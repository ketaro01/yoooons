# YOOOONS

소프트웨어 개발자 윤대훈의 포트폴리오입니다. 웹 서비스부터 데이터·AI 플랫폼까지 참여한 프로젝트와 개발 경험을 소개합니다.

화면과 API 개발, 공통 프레임워크 구축, 레거시 마이그레이션, 재사용 가능한 라이브러리 개발 경험을 프로젝트별 역할과 함께 정리했습니다. AI 코딩 도구를 개발 과정에서 활용하는 방식도 담았습니다.

## 주요 구성

- **소개** — 개발을 시작한 계기와 서비스의 구조를 개선해온 경험
- **프로젝트** — 분야별 필터와 상세 화면으로 살펴보는 담당 기능·기여·기술 스택
- **AI 개발 방식** — OpenCode, MCP, Agent Skills, GSD를 활용하는 작업 과정
- **경력** — 회사별 주요 업무와 이전 프로젝트

다크 테마와 넓은 여백을 바탕으로 구성했습니다. 제목의 은빛 하이라이트, 스크롤 진입 효과, 메인 그래픽의 부유 애니메이션을 적용했으며 모바일 레이아웃과 모션 감소 설정을 지원합니다. 프로젝트 썸네일은 실제 제품 화면 대신 CSS·SVG로 만든 컨셉 그래픽입니다.

## 기술 스택

| 영역 | 기술 |
| --- | --- |
| UI | React, TypeScript |
| 개발·빌드 | Vite, Bun |
| 스타일 | Sass |
| 컴포넌트 구성 | Atomic Design |

별도 서버나 API 키 없이 실행되는 정적 웹 애플리케이션입니다.

## 시작하기

Bun을 설치한 뒤 저장소 루트에서 실행합니다.

```sh
bun install --frozen-lockfile
bun run dev
```

## 프로젝트 구조

```text
src/
  components/
    atoms/       # 아이콘, 태그, 제목 등 기본 요소
    molecules/   # 프로젝트 카드와 시각 요소
    organisms/   # 소개, 프로젝트, 경력 등 섹션
    templates/   # 페이지 레이아웃
  pages/         # 페이지 구성
  data/          # 소개, 프로젝트, 경력 데이터
  hooks/         # 스크롤 및 모션 동작
  styles/        # Sass 토큰과 컴포넌트 스타일
  types/         # 데이터 타입
```

콘텐츠와 화면 컴포넌트를 분리해 경력과 프로젝트를 갱신할 수 있도록 구성했습니다. Pretendard 폰트의 라이선스는 [public/fonts/LICENSE.txt](public/fonts/LICENSE.txt)에 있습니다.
